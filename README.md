# 🏆 Codeforces Contest & Problem Generator

A modern web application for competitive programmers to generate personalized **Codeforces practice problem sets** and simulate virtual contests.

Create custom problem sets, filter out solved problems, practice with multiple Codeforces handles, and track your progress — all in one place.

---

## 🌐 Live Demo

👉 https://codeforces-random-problem-and-conte.vercel.app/

---

## ✨ Features

- 🎯 **Custom Problem Generator**  
  Generate personalized practice sets from thousands of Codeforces problems.

- 👥 **Multi-User Unsolved Filter**  
  Add multiple Codeforces handles and automatically exclude problems solved by any of them.

- ⏱️ **Virtual Contest Mode**  
  Simulate a real contest with a countdown timer and live solving progress.

- 🔍 **Solution Status Checker**  
  Quickly check whether a problem has been solved by your selected users.

- 🎚️ **Flexible Filtering**  
  Customize your problem selection based on difficulty, tags, rating, and other criteria.

- ☀️🌙 **Light & Dark Mode**  
  Switch between a clean light theme and a comfortable dark theme.
